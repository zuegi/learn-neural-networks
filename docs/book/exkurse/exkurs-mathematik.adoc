== Exkurs: Mathematische Grundlagen

Dieser Exkurs fasst die mathematischen Kernideen zusammen, die in den Kapiteln zu Embeddings und Training verwendet werden.

=== Vektoren und Matrizen

* Ein **Vektor** ist eine Liste reeller Zahlen, z. B. `x in R^d`.
* Eine **Matrix** ist eine Tabelle aus Zahlen, z. B. `W in R^(n x d)`.

Im Embedding-Kontext:

* `d` = `embeddingDim`
* `n` = `vocabSize`
* jede Zeile von `W` ist ein Token-Vektor

=== Shapes als Denkwerkzeug

Shapes helfen, Rechenfehler früh zu vermeiden.

Beispiele:

* Embedding-Matrix: `[vocabSize, embeddingDim]`
* Sequenz-Embeddings: `[seqLen, embeddingDim]`
* Gradienten im Backward: gleiche Form wie Forward-Ausgabe

=== Elementweise Operationen

Viele Schritte in Embeddings sind elementweise:

* Addition: `z = a + b`
* Subtraktion: `z = a - b`
* Skalierung: `z = eta * g`

Wichtig für Updates:

`weights = weights - learningRate * grad`

=== Dot Product (Skalarprodukt)

Für zwei Vektoren `a, b in R^d`:

`a · b = sum_(i=1..d) (a_i * b_i)`

Intuition:

* großer positiver Wert -> ähnliche Richtung
* nahe 0 -> wenig ausgerichtet
* negativer Wert -> entgegengesetzte Richtung

Das Skalarprodukt ist später zentral für Attention-Scores.

=== Gradient und Backpropagation

Ein Gradient zeigt, wie stark sich der Loss ändert, wenn ein Parameter minimal verändert wird.

Bei trainierbaren Embeddings:

* `forward` liest bestimmte Zeilen aus `weights`
* `backward` verteilt Gradienten zurück auf genau diese Zeilen
* bei mehrfach vorkommenden Token-IDs werden Beiträge addiert

Das ist ein **sparse update**:
nur verwendete Token-Zeilen bekommen in einem Schritt ein Signal.

=== SGD-Update

Ein einfacher Optimizer ist Stochastic Gradient Descent (SGD):

`w_new = w_old - eta * grad`

mit:

* `eta` = Lernrate (`learningRate`)
* `grad` = aktueller Gradient

Zu große Lernrate -> instabil.
Zu kleine Lernrate -> sehr langsames Lernen.

=== Warum das für das Buch wichtig ist

Die Kapitel bauen darauf auf, dass du Shapes, elementweise Updates und Gradientenfluss sicher lesen kannst.
Damit werden Implementierungen wie `TrainableTokenEmbedding` direkt nachvollziehbar.

== Mathematische Ableitung
Die mathematische Ableitung beschreibt, wie stark sich eine Funktion an einem bestimmten Punkt verändert. Man kann sie sich wie die Momentangeschwindigkeit auf einem Tacho vorstellen.Hier ist die einfache Erklärung in drei Schritten:

* Die Steigung messen: Wenn man zwei Punkte auf einer Kurve verbindet, kann man die durchschnittliche Steigung zwischen ihnen berechnen (wie ein Höhenunterschied auf einer Wanderung).
* Die Punkte zusammenschieben: Um die Steigung an einem exakten Punkt zu erfahren, schiebt man den zweiten Punkt in Gedanken unendlich nah an den ersten heran.
* Das Ergebnis (Der Grenzwert): Aus der Linie zwischen zwei Punkten wird eine Berührungslinie (Tangente), die die Kurve nur noch an diesem einen Punkt berührt. Die Steigung dieser Tangente ist die Ableitung.

Beim Gradientenabstieg nutzt man diese Ableitung für mehrere Richtungen gleichzeitig, um zu wissen, wie steil der Berg nach unten führt.

=== Beispiel: Gradientenabstieg (Gradient Descent)

Dieses Dokument zeigt ein konkretes mathematisches Beispiel für den Gradientenabstieg anhand einer einfachen Funktion. Das Ziel ist es, den tiefsten Punkt einer parabelmöglichen Schüssel zu finden.

==== 1. Die Ausgangslage

* *Fehlerfunktion (Loss-Funktion):* f(x) = x^2
* *Startpunkt:* x = 3
* *Lernrate (Step Size):* eta = 0.1

Das absolute Minimum dieser Funktion liegt bei x = 0. Der Algorithmus startet bei x = 3 und versucht, sich diesem Minimum schrittweise zu nähern.

==== 2. Die Berechnung des ersten Schritts

Der Algorithmus führt nacheinander drei Kernschritte aus, um die Position zu aktualisieren.

===== Schritt A: Die Ableitung bilden
Die Ableitung gibt die Steigung der Funktion an jedem beliebigen Punkt x an.
[stem]
----
f'(x) = 2x
----

===== Schritt B: Die aktuelle Steigung berechnen
Wir setzen unseren aktuellen Startpunkt (x = 3) in die abgeleitete Funktion ein:
[stem]
++++
f'(3) = 2 * 3 = 6
++++
Die Steigung beträgt +6. Das bedeutet, die Funktion steigt an dieser Stelle nach rechts hin an.

===== Schritt C: Den neuen Punkt berechnen
Um das Minimum zu finden, müssen wir uns entgegen der Steigung (nach unten) bewegen. Die Aktualisierungsformel lautet:
[stem]
++++
x_{neu} = x_{alt} - (\eta * f'(x_{alt}))
++++

Wir setzen unsere Werte in die Formel ein:
[stem]
++++
x_{neu} = 3 - (0.1 * 6) = 3 - 0.6 = 2.4
++++

==== 3. Fazit und Ausblick

Nach dem ersten Durchlauf ist der Wert von x = 3 auf x = 2.4 gesunken. Der Algorithmus hat sich damit erfolgreich in Richtung des Minimums (x = 0) bewegt. Im nächsten Schritt würde das Verfahren mit dem neuen Ausgangswert x = 2.4 exakt gleich wiederholt werden.
